# Experiment rules

Use only synthetic records in this experiment.
Keep book principles separate from implementation choices and measured results.
Preserve all failing model outcomes in the experiment report.
Do not send prompts to a paid or remote model without user authorization.
The user authorized OpenAI API integration for synthetic records on 2026-10-26.
Use the OpenAI Responses API when model trials are requested.
Read the API key from OPENAI_API_KEY. Never save or display the key.
The default replay and tests must not call a model service.
Keep historical Qwen observations separate from OpenAI observations.
The user approved hybrid retrieval on 2026-10-26.
Apply access and validity checks before embedding or ranking.
Label hand-authored test vectors separately from actual provider embeddings.
Offline replay must report lexical fallback when its embedding cache is incomplete.
Do not modify the books or the earlier learning diagrams.
Run tests after changes to memory behavior.
Keep private reasoning outside saved traces.
Save observable decisions, evidence references, tool actions, and results.
Keep editable demo assets in src/demo and the generated portable demo in runs/demo.html.
Put current verification outputs in runs/verification.
Preserve historical model evidence in runs/history without attaching it to current OpenAI results.
Use Python's -B option in project commands to avoid generated bytecode in source folders.
